# OSKO Camera — Project Status

## Current stage
**Active working prototype / pre-release build.**

This is no longer only an idea. The camera is running as a real web app with live camera access, photo capture, video, zoom controls, rear flashlight control, document scanning, code scanning, notes, sharing, saving, and OSKO-specific tools.

## What is already built
- Live rear and front camera
- Photo capture
- Video recording
- Hardware zoom detection and numbered zoom controls
- Tap-to-focus where the phone/browser permits it
- Continuous focus, exposure, and white-balance requests
- High-resolution still capture through ImageCapture when supported
- Rear flashlight / torch control
- Torch glare protection where exposure compensation is supported
- Date/time and location stamps
- Document scanner
- QR and barcode scanning
- Gallery, saving, sharing, Drive workflow, notes, stickers, and website copies
- Offline app caching

## What remains before calling it finished
- Full testing on Osko's actual Android phone
- Confirming the closest sharp focus distance
- Confirming the farthest clear zoom before detail breaks down
- Testing flashlight glare at close range
- Testing daylight, indoor, low-light, front-camera, photo save, video save, and offline reopening
- Fixing any phone-specific failures found during testing
- Packaging and confirming a clean phone installation

## Public wording
Use this wording:

> OSKO Camera is now in active pre-release testing. The working camera and major tools are built. We are finishing phone-specific clarity, zoom, flashlight, saving, and installation testing before the first release.

Do not call it a concept or an idea. Do not call it fully finished until the real-phone test list passes.

## Release rule
The first release is ready when the main camera can reliably open, focus, capture a clear full-quality photo, use tested zoom, operate the rear light, save the result, and reopen it on Osko's phone without losing the image.
